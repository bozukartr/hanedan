# HANEDAN güncellemeleri

Her güncellemeyi güncel main üzerinden açılmış yeni bir dalda hazırla. Tamamlanan güncellemeyi bu dala gönder. GitHub Actions, main hedefli PR açar veya mevcut PR’ı kullanır, birleşim sonucunu test eder ve başarılıysa birleştirerek Pages yayınını başlatır. Sonucu PR ve yayın çalıştırmasından doğrula.
